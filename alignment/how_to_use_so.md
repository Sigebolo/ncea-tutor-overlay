# 使用指南（给孩子 SO）

## 一、怎么打开

电脑开着时：

1. 双击项目里的 **`start.bat`**（Windows 双击即用，会自动打开浏览器）
2. 如果浏览器没自动打开，手动访问：**http://localhost:3782**
3. 学完后不用关，下次直接打开浏览器就行；如需停止服务，告诉我

> 如果打不开，告诉我，我帮你检查。

## 二、每次学习怎么开始（重要！）

打开后找到聊天框，**第一句话这样说**：

```
我在复习 AS 91579 Integration（积分），external，目标 Excellence，只做 E 的题。
```

老师听到这句话就会：

- 确认标准（AS 91579）、内外（external）、目标（E）
- 先上 **真题**：从最新年份的 NZQA 卷子里原题照搬（会告诉你哪年哪题），真题刷完才出变式题
- 只盯 **E 难度**的部分（不浪费时间做简单题）
- 根据评分标准（assessment schedule）讲清楚"为什么这题是 E"
- 引用资料时告诉你依据哪份 NZQA 文档（标准、考试说明、评分标准、评估报告、历年卷）

## 三、一次 45 分钟的学习流程（建议）

| 时间 | 做什么 |
|---|---|
| 0–5 分钟 | 告诉老师："上次的错题复习一下"（老师会查学习记忆） |
| 5–30 分钟 | 做 E 题：老师出题 → 你写答案 → 老师按评分标准打分并讲解 |
| 30–40 分钟 | 口头解释练习：不用写，**说出来**"为什么这个积分这样解"，老师对照评分标准的 E 表述检查 |
| 40–45 分钟 | 总结：今天学到了什么、错在哪、明天复习什么 |

## 四、换科目怎么换

在聊天界面里切换**知识库（Knowledge Base）**：

| 科目 | 选这个知识库 |
|---|---|
| 数学 L3 积分（当前默认） | `NZQA_C3_AS91579_Integration` |
| 数学 L3 其他 | `NZQA_C3_AS91577_ComplexNumbers` / `NZQA_C3_AS91578_DiffMethods` |
| 物理 L2 | `NZQA_P2_AS91171_Mechanics`（力学）/ `NZQA_P2_AS91170_Waves`（波）/ `NZQA_P2_AS91173_ElectricityEM`（电） |
| 化学 L2 | `NZQA_C2_AS91164_Bonding`（成键）/ `NZQA_C2_AS91165_Organic`（有机）/ `NZQA_C2_AS91166_Reactivity`（反应）/ `NZQA_C2_AS91167_QuantAnalysis`（定量分析） |
| 统计 L3 | `NZQA_S3_AS91586_ProbDist` 等 5 个 |

换完知识库后再说一遍开场白，比如：

```
我在复习 AS 91171 力学，external，目标 E，只做 E 的题。
```

## 五、老师会遵守的规矩（放心用）

- **E 优先**：默认只出 E 题，除非你自己说"来道简单的"
- **不代写作业**：internal（校内评估）的作业，老师只教方法和练习，不帮你写
- **答案有依据**：每次讲解都会说"这是按 2023 年评分标准……"并引用资料
- **练习反馈**：老师说"这能拿 E"只是练习评估，最后成绩由学校老师定

## 六、小技巧

- 卡住了就说："提示一下，别直接给答案"（苏格拉底式引导）
- 想对答案格式："帮我看看我写的和 E 的标准答案差在哪"
- 快考试时："按 2021–2025 年真题风格出 3 道 E 题，计时 20 分钟"
- 不会的英文术语可以问中文，老师会中英对照讲
