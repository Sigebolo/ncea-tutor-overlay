## 91577-2024-Q2b · 2024 Exam Q2(b) · Achieved

- Topic: values of r so 2x^2 + (3 + 2r)x + (3 - 2r) = 0 has equal roots.
- Answer: (3+2r)^2 - 8(3-2r) = 0 → 4r^2 + 28r - 15 = 0 → (2r - 1)(2r + 15) = 0 → r = 0.5 or r = -7.5.

## 91577-2023-Q3e · 2023 Exam Q3(e) · Excellence

## 91577-2025-Q1c · 2025 Exam Q1(c) · Excellence

- Location: 91577-exm-2025.pdf, Question One (c).
- Topic: prove a quadratic in x (coefficients in k) has real roots for all real k.
- Answer: Δ = k^2 + 12k^2 = 13k^2 > 0 for all k (alt. form Δ = 1 + 12k^4 > 0), hence roots always real.
