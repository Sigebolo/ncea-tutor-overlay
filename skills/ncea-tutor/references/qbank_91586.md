  (c) σ ≤ 6.47 (P(X < 17) = 0.000998 < 0.001 and P(X > 70) < 0.01 at σ = 6.47; minimum σ ≈ 6.47).

## 91586-2025-Q3 · 2025 Exam Q3 · Achieved/Merit/Excellence

- Location: 91586-exm-2025.pdf, Question Three (harmful-content screening: binomial + false positives).
- Topic: (a) P(fewer than 3 harmful of 20 posts, 1 in 10 harmful) binomial n = 20, p = 0.1;
  (b) independence assumption; (c) false-positives distribution X (per batch of 100): E(X) and Poisson
  usefulness; (d) competing system: P(X = 0) = 0.03 → λ, compare.
- Answer: (a) P(X < 3) = P(X ≤ 2) = 0.6769. (b) independence: one post being harmful does not affect
  another — unlikely valid since all 20 are by the same user (similar language → clustered detections).
  (c)(i) E(X) = 2.1 false positives per 100. (c)(ii) Poisson useful: rare events, independence, rate
  proportional to batch size, random/unpredictable reporting. (d) λ = −ln(0.03) = 3.51 false positives
  per 100 vs 2.1 → competing system less accurate (higher false-positive rate).
- Tier/marks: NØ/N1/N2, A3/A4, M5/M6, E7/E8 (cut scores as above).
- Verified: matches 91586-ass-2025.pdf pp5-6. HIGH.

## 91586-2023-Q1 · 2023 Exam Q1 · Achieved/Merit/Excellence

- Location: 91586-exm-2023.pdf, Question One (sheep stocking rate: Poisson; Awassi wool fineness: uniform).
- Topic: (a) mean 9 sheep/ha — P(> 10 sheep); why flocking affects the model; (b) wool fineness
  uniform 20–60 µm — P(> 35), simulation-fit judgement, P(25 < X < 40) for four sheep, independence assumption.
- Answer: (a)(i) Poisson λ = 9: P(X > 10) = 1 − P(X ≤ 10) = 0.2940. (a)(ii) flocking breaks Poisson
  assumptions: sheep are not randomly/independently located (one sheep implies neighbours) and the
  per-hectare rate is not constant across land. (b)(i) uniform a = 20, b = 60: P(X > 35)
  = (60 − 35)/(60 − 20) = 0.625. (b)(ii) observed frequencies sit inside the simulation grey band
  (sampling variation) → uniform model appropriate. (b)(iii) P(25 < X < 40) = 0.375 for one sheep;
  0.375⁴ = 0.0198 for four. (b)(iv) independence: one sheep's fineness does not affect another's.
- Tier/marks: NØ/N1/N2, A3/A4, M5/M6, E7/E8 (cut scores 0–6 NA, 7–13 A, 14–18 M, 19–24 E per 91586-ass-2023.pdf).
