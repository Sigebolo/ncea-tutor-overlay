## 91166-2022-Q1aii · 2022 Exam Q1(a)(ii) · Achieved/Merit

- Location: 91166-exm-2022.pdf, Question One (a)(ii), H2/I2/HI equilibrium.
- Topic: Kc value from equilibrium concentrations.
  0.105 mol L–1 for both H2(g) and I2(g), while the concentration of HI is
  0.711 mol L–1. Calculate the value of Kc."
- Answer: Kc = [HI]²/([H2][I2]) = 0.711² / (0.105 × 0.105) = 45.9.
- Verified: arithmetic re-done + schedule: A = calculation from incorrect Kc,
  Merit = correct answer. HIGH.

## 91166-2024-Q2bi · 2024 Exam Q2(b)(i) · Achieved/Merit/Excellence

- Location: 91166-exm-2024.pdf, Question Two (b)(i), SO2/SO3/O2 mixture.
- Topic: reaction quotient Qc vs Kc to test equilibrium.
  0.620 mol L–1. Using a calculation, explain why this reaction is not at
  equilibrium."
- Answer: Qc = 0.620²/(0.530² × 0.710) = 1.93 ≠ Kc (32.7) → not at
  equilibrium; Qc < Kc so the forward reaction is favoured until Qc rises
  to Kc.
- Verified: arithmetic re-done + schedule: A = substitution, M = correct
  value (1.93), E = value with full justification. HIGH.
