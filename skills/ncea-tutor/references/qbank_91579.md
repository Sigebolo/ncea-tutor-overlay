## 91579-2024-Q1c · 2024 Exam Q1(c) · Achieved/Merit

- Location: 91579-exm-2024.pdf, Question One (c).
- Topic: distance from a velocity function by integration, with an initial condition.
  where v is the velocity of the object in m s–1, and t is the time in seconds since the start of
  timing. Initially, the object was 360 metres from a point P. Calculate the distance that this
  object has travelled from the point P when it has reached a velocity of 264 m s–1. You must
  use calculus and show the results of any integration needed to solve the problem."
- Answer: d = ∫26.4 t^(1/3) dt = 19.8 t^(4/3) + c; with t = 0, d = 360 → c = 360, so
  d = 19.8 t^(4/3) + 360. v = 264 gives 26.4 t^(1/3) = 264 → t = 1000 s; d = 198 000 + 360
  = 198 360 m.
- Tier/marks: the schedule prints for (c) "Reaching stage (1) of the solution" (Achievement)
  and "Correct solution, with evidence of correct integration. Accept any reasonable rounding.
  Units not required." (Merit); no separate Excellence bullet is printed for this part.
- Verified: question verified in 91579-exm-2024.pdf Q1(c); the full worked solution
  (d = 19.8 t^(4/3) + 360, t = 1000, d = 198 360 m) and both tier bullets read directly from
  91579-ass-2024.pdf Q ONE (c); arithmetic re-derived. HIGH.
