# Verified question index — AS91098 Analyse specified aspect(s) of studied written text(s) (English L2)

(free on nzqa.govt.nz). Give the LOCATION (year + question), never

- Answer/criteria: Achievement — structured essay using analysis terminology; addresses chosen
  question/aspect; states a relevant idea; shows awareness of the use of the specified
  aspect(s); includes details from the text(s). Merit — convinces by engaging with the
